JVM 诊断助手，基于 Arthas 的自然语言诊断工具。

## 简介

ArthasClaw 是一个基于 Arthas 的 JVM 诊断工具，通过自然语言交互方式，让开发者无需记忆复杂的 Arthas 命令，即可快速诊断 Java 应用问题。

## 特性

- 🤖 **自然语言交互**：用中文/英文提问，自动解析意图
- 📊 **智能分析报告**：AI 解读诊断结果
- 💻 **多模式支持**：自然语言、Arthas 命令、Shell 命令
